New here? A quick walkthrough
  1. Choose a template. Pick the visual model and skin. It can differ from the physical gamepad. Previewing keeps your current job intact until you apply it.
  2. Customize. Use the tabs for colors, artwork and finishes. Drag the controller or choose Move artwork. Undo restores changes.
  3. Check inputs. Try input demo needs no controller. For verification, choose Live controller and run the physical input check.
  4. Review the customer experience. Export & OBS opens a customer preview in the Windows app. The customer receives a hosted overlay URL and setup guide, without installing this editor.

Ctrl+K / Command+K finds tools. Ctrl+S saves a project. Esc closes this panel. No account is needed to design or try the demo.
