OVERLAY STUDIO — INTERNAL PRODUCTION TOOL — 0.22.0 WINDOWS PRERELEASE

This application is for the producer. Customers receive a hosted overlay URL.

START
Use Find a tool (Ctrl+K / Command+K or F1) to search for an action.
Try input demo works without a controller and never counts as physical verification.

1. Extract the entire Windows ZIP. Open Overlay Studio.exe and keep the
   adjacent files and folders together. Run one copy at a time.
2. Choose a visual model and skin and select Use, or continue/open a saved
   job. Start without a template previews the neutral overlay.
   Previewing a skin leaves your current job untouched until you apply it.
   Connect any browser-standard gamepad, focus the app and press a button.
   The visual layout and physical input device are independent. Face inputs
   follow bottom/right/left/top positions, regardless of printed letters.
   Keep current customization carries your design into another model.
   The preview starts in Live controller mode automatically.
3. Use the searchable skin gallery to choose your base. Your job name is in
   the header, tools on the left, and appearance settings on the right.
   Check Controller input below the preview for connection feedback. Auto keeps the active
   compatible device; choose Input device to use a specific controller.
   If a selected device reconnects in another browser slot, select it again.
4. Shell > Use default overlay restores the current model’s default while
   preserving the job name. Undo restores the previous design. Project options >
   Reset to selected skin restores that skin separately.
   Use Shell, Buttons, Artwork, Effects, Layout, Holographic, Abstract, Textures and
   Presets to customize the chosen controller artwork. Drag the preview to move the
   controller, or choose Move artwork to position your text/logo separately.
   Movement controls sit above the preview. Arrow keys nudge; hold Shift for
   10 pixels. Content outside the canvas crops. Verify inputs opens the physical
   check without starting it. Quick setup help is available below the preview.
5. Artwork lets you choose Text artwork, import a PNG/JPEG logo, and return
   to Use imported logo after trying text. Use original template artwork restores the chosen artwork view.
6. Save project creates an editable .overlay backup with its images embedded.
   Autosave restores the last design on this computer when storage is available.
   Ctrl+S saves; Ctrl+O opens; Ctrl+Z undoes; Ctrl+Shift+Z redoes.

CUSTOMER DELIVERY — REPOSITORY FIRST
Use BrandonFromFresno/Controlverlay-Farm as the single upload repository.
In Export & OBS > Customer delivery > GitHub connection, enter a fine-grained
GitHub token scoped to that repository, Contents read/write only. Leave Free
hosting URL empty for now. Windows protects the token; never send it to
customers or paste it into chat.
Uploads are marked Saved in the repository and show their file path. They
are not yet live browser-source URLs. Customer handoff remains disabled.

HOSTING LATER (OPTIONAL)
Connect the repository to Cloudflare Pages Free: main branch, framework None,
no build command, output directory /. Save its HTTPS pages.dev URL in the app.
Leave the token empty to reuse this repository's protected connection. Stored
overlays get URLs without another upload. No paid hosting plan, purchased
domain or Cloudflare API token is required within free limits.

CUSTOMER REVIEW
Export & OBS > Preview customer experience opens a separate Windows review
window with direct controller input. No GitHub connection is needed. Local
review URLs expire and cannot be copied as customer delivery URLs.

CUSTOMER DELIVERY — EACH JOB
Name the job before saving; filenames use that name. Customize a reusable
configuration, then run Verify customer inputs with the physical controller.
The check observes press/release, trigger depth, full stick travel and diagonals.
Home is optional where exposed; vendor-only buttons remain preview-only.
Use included fonts for delivery text so customers need no font installation.
Upload customer overlay saves a private editable backup and sends one finished
page to the repository. Earlier customer versions are preserved. Wait for the
live-URL check, test that URL in OBS/Streamlabs with the game focused and after
reconnect, then confirm and copy the handoff. Reopen earlier deliveries from
private backups without changing their existing customer URLs.
New handoffs include a setup guide (the same URL with setup=1) and the clean
overlay URL. The setup guide shows live status, activation help and Copy OBS URL.
The copied clean URL displays only the transparent overlay, without instructions.
Customers only add the supplied Browser Source URL at 1672 x 1241. They do
not install this application, assemble assets or edit code. The customer page
reads their own controller directly; it does not need your local bridge.

STUDIO OBS TESTING (NOT A CUSTOMER URL)
1. Open Export & OBS, then choose Send design to OBS.
2. In OBS: Sources > + > Browser > Create new. Leave Local file OFF.
3. Paste http://127.0.0.1:18777/overlay
4. Set Width to 1672 and Height to 1241. Keep Overlay Studio running.
5. After editing, choose Update OBS overlay, then refresh the Browser Source.
   Older exported HTML files do not update themselves.

Overlay page connected means a browser source/page has connected to the local
bridge; confirm the picture in OBS. If the connection is unavailable, close
other copies of Overlay Studio and use Retry local connection.

INPUT AND PREVIEWS
Effects > Button press & analog effects offers four press bursts and four
continuous responses. Choose trigger depth, stick movement or both; adjust
color, strength, size and burst duration. These use travel/deflection, not
physical force. Try effect demo cycles both sticks and triggers. Still mode
pauses these effects while normal pressed highlights keep working.

Only standard browser gamepad mapping is supported. Home depends on what
Windows exposes. Capture, M and vendor-only inputs remain preview-only.
Preview & test options contains Rest, Peak glow, demo and simulated presses.
Those simulations are not forwarded to OBS: OBS receives physical input.
Disconnecting releases physical input. Page interruptions release it too;
unclean interruptions use a one-second stale-input timeout in the overlay.

EXPORTS AND FONTS
Export overlay HTML embeds the selected visual assets and included font.
Live input still requires this computer's running desktop app/local bridge.
Export PNG still saves a transparent 1672 x 1241 image at peak glow.
Included fonts work offline. Fonts on this computer uses installed families;
install the same system font on another computer that displays the overlay.
Font source/license notices are included inside resources/app.asar.

RECOVERY
Retry loading retries controller artwork/font loading without resetting your
current design. Invalid saved artwork can be replaced, or select Text artwork.
If autosave is unavailable, save a project file. Refresh/reopen restores the
saved design and selected device; simulated presses are temporary.
New neutral design resets the appearance; Undo restores your work.

KNOWN LIMITS
This prerelease is unsigned and intended for producer acceptance testing. Windows executable
launch, physical controller input, focus/minimize behavior and OBS capture need final
hardware validation. Nothing in browser tests measures 8 kHz polling/latency.
The provided base has faint baked reference artwork. The controller is an
existing 2D raster/vector template; this editor does not create a 3D model.
Hard crashes/power loss may lose edits inside the autosave debounce window.

No account, Node.js, internet or GameSir server is required to run the extracted
app. Reference websites are optional. Imported textures and projects stay local.

FREE HOSTING CAPACITY AND TARGET-APP CHECK
Cloudflare Pages Free currently allows 500 builds/month, 20,000 files/site
and 25 MiB/file. The app rejects customer files exceeding the file limit.
Each retained version counts separately; review repository growth as it grows.
Browser-host background-input regressions exist, including OBS 33.0.1 on
Windows. Test the exact supported OBS/Streamlabs version before handoff.
Hosting alone cannot make an unsupported Gamepad API work.

COMIC GUNFIRE FX
Effects > Right trigger > Comic Gunfire FX is optional and starts off.
Enable it, choose a word or Random, and use Preview RT for a simulated burst.
Hold RT to repeat supports configurable firing interval and a bounded burst count.
Advanced settings include placement, intensity, rotation and activation threshold.
The full animation is auto-fitted to clear space; the panel reports size reduction.
Select Live controller after previewing to verify actual RT input.
Customer exports include all four graphics with true transparency.
Re-export an older job to deliver the new effects. Existing customer URLs stay intact.

JOYSTICK STYLES
Effects > Joystick movement & trails offers Tilt, Both and Trail.
Tilt preserves the original cap movement. Both adds a fading path.
Trail keeps the cap centered while a marker shows the current input.
Choose Short, Medium or Long and a preset or custom trail color.
The fixed sockets/rims and stick-click feedback are preserved.
Try input demo previews both sticks; select Live controller to test hardware.

SCUF IMPACT FRONT PREVIEW
The supplied pearl front artwork supports 14 front-control inputs, including
both sticks/clicks and optional browser touchpad click (button 17).
Complete bumper, trigger and rear-paddle artwork was not supplied. Those inputs
are not visualized by this preview template. Finish and physically verify
these surfaces before offering a complete SCUF customer overlay.
