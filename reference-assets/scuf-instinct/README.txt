SCUF XBOX — ORANGE-RING LAYERED ARTWORK

Prepared from the supplied images, using the larger orange-ring reference for
the finish. Includes a newly refined assembled render and a matching shell
with reconstructed recesses, plus transparent aligned components.

IMPORT
Read alignment.json for exact canvas size, layer order and pivot coordinates.
Place all PNGs at (0,0), at native export size. Do not trim or independently
center them. The named-layer SVG references the adjacent layers folder; keep
that folder in place when opening the SVG in Inkscape. This is raster-backed
artwork, not a pure-vector controller model.

ANIMATION
Keep the body and socket layers stationary. Move only the isolated stick caps.
The complete circular segmented D-pad is one sprite with a shared pivot.
The face buttons, View, Menu, Share, Xbox Home, mute button, and indicator are
separate components. Hidden wells are reconstructed visual approximations.

LIMITS
Only visible shoulder portions are included. The references do not establish
four independent complete bumper/trigger surfaces or rear controls. Physical
travel, response timing and engine input mappings are not verified by stills.
Static alignment, transparency, reassembly and offset-stick states are checked.
This artwork is generatively refined, not dimensionally certified 1:1 geometry.
Native render size and working export size are recorded in alignment.json.
Export enlargement does not imply additional native rendered detail.
No third-party reuse-permission statement was supplied.
