# Artwork for additional rendered controller templates

For each model, supply one folder containing the highest-quality original artwork you have and any variant folders. Native PSD/SVG/Blender files are welcome; the application integration can extract and measure the parts. The artist does not need to write configuration code.

## Best source pack

- Accurate straight-on front view, preferably orthographic, on transparent background. Aim for a controller at least 1600–2000px wide; 2500–4000px is useful for large exports and future work.
- Separate housing/faceplate, contrasting center/grip panels, fixed stick wells/rims and movable stick caps. Include complete artwork beneath moving parts so motion never reveals a hole or a duplicated cap.
- Separate face buttons, D-pad directions or a clean shared D-pad, bumpers, triggers, utility and center buttons. Include printed legends and permanent branding on separate layers where possible.
- Clean transparency, soft material shading, seams, reflections and texture detail. Optional shadow/highlight/AO layers make recoloring cleaner. A raw dark 8-bit flattened image has less latitude for bright colorways.
- Coordinated regional palettes: housing, grips/center, touchpad, sticks, buttons, hardware and lighting. Avoid tinting every component the same color by default.
- Permission covering modification and commercial redistribution in customer overlays. Retain the artist's attribution and the permission/license record.

## Useful reference and testing material

Include the exact model/revision, clear front/shoulder photographs and a short input demo if available. A diagram or video should show the button labels, trigger neutral/full travel, both sticks moving to their limits and clicking, diagonals, and any extra controls. Describe how optional/vendor buttons are exposed or mapped; artwork alone does not establish functional input support.

## Integration work

The current renderer, universal standard-gamepad input, customization, preset and delivery systems can be reused. Work for each model is primarily source-layer preparation, measured placement/pivots/travel, precise masks, shading/recoloring calibration, coordinated starting finishes and verification. A single flattened PNG generally needs more manual separation and background reconstruction. A layered original or reusable 3D source offers a cleaner path to repeatable quality.

Acceptance includes neutral/full/combined inputs, stationary visible rims, no ghost caps or clipping, readable press states, source-size and OBS-size visual review, saved-project restore and a self-contained customer export. Physical-controller/driver and OBS/Streamlabs testing remain part of final acceptance.
